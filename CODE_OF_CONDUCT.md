# Code of Conduct

PayCal's public repository exists to improve a privacy-first work-hours and pay-visibility product. Participation should be direct, useful, and respectful.

## Expected Behavior

- Keep discussions focused on the technical or product issue being reported.
- Assume sensitive user, worker, business, and pay data deserve careful handling.
- Provide reproducible details for bugs and concrete acceptance criteria for feature requests.
- Disagree with ideas by explaining evidence, risk, and tradeoffs.
- Respect maintainers' decisions about scope, license boundaries, roadmap fit, and release timing.

## Unacceptable Behavior

- Harassment, threats, insults, doxxing, or discriminatory language.
- Posting secrets, personal data, payroll data, private screenshots, or vulnerability details in public issues.
- Repeated off-topic comments, spam, or demands for support outside the documented channels.
- Attempts to bypass security, privacy, licensing, or repository access controls.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests; block users; or report conduct to GitHub when needed. Security reports should be sent to `security@paycal.app` instead of public issue threads.
